# Chord for iOS

Release builds of Chord for iOS. This repository holds only releases. The source is in the Chord
repository.

There is no iOS app yet.

**[Download the latest release](https://github.com/abbyfluoroethane/chord-iOS/releases/latest)**. Betas are listed as
pre-releases on the [releases page](https://github.com/abbyfluoroethane/chord-iOS/releases).

## Versions

- A release is `MAJOR.MINOR.PATCH`, tagged `v0.3.0`.
- A beta is `MAJOR.MINOR.PATCH-beta.N`, tagged `v0.3.0-beta.2+<commit>`: the version it leads to, a counter, and the commit it was built from.

Each release lists the SHA-256 of its files in `SHA256SUMS`.
